# 🎨 Color Palette Generator

Generate harmonious color palettes in one click, and copy them as hex codes or CSS variables.

🔗 **Live demo:** https://meena-y-tech.github.io/color-palette/

## Features
- 4 modes: Random, Complementary, Analogous, Triadic (built on HSL color theory)
- Click any color to copy its hex code
- Copy the full palette as CSS variables
- Press Space to generate a new palette
- Responsive, with no dependencies

## Tech
HTML, CSS, vanilla JavaScript

## Run locally
Download or clone the repo and open `index.html` in a browser.
